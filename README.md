## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools bundled with a universal loader for Windows desktop. It packages Volt, Synapse Z, Potassium, Wave, and xcutorsLoader into a single convenient installer.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 64-bit and 32-bit editions are supported, though 64-bit is recommended for best performance.

### Do I need to disable my anticomponent to install XCutors?

Some anticomponent programs may flag script executors as potentially unwanted programs (PUPs). You may need to add the XCutors installation folder to your anticomponent exclusion list. Always download only from this official repository to ensure file integrity.

### How do I switch between different executors?

Use the xcutorsLoader universal loader included in the package. From the main XCutors dashboard, select your preferred executor backend from the dropdown menu and click 'Load.' The loader handles all configuration automatically.

### Is XCutors free to use?

Yes, XCutors itself is free and open-source. However, some individual executors included in the collection may require their own separate license or key. Please check each executor's documentation for licensing details.

### Why does the executor fail to attach to Roblox?

Ensure Roblox is running and fully loaded into a game before clicking 'Attach.' Also verify that your anticomponent is not blocking the process and that you launched XCutors with administrator privileges. Restarting both applications usually resolves most attachment issues.

### Where can I find scripts to use with XCutors?

XCutors includes a built-in script hub with categorized scripts. You can also find community-shared scripts on popular Roblox scripting forums and repositories. Simply paste any Lua script into the editor or drag a .lua file into the window.

### How do I update XCutors and its bundled executors?

XCutors includes a built-in auto-update checker. When a new version is available, you will be notified on launch. You can also manually download the latest release from this repository's Releases page and reinstall over your existing setup.

### Can I use XCutors on multiple monitors?

Yes, XCutors fully supports multi-monitor setups. The executor window can be freely moved and resized across any connected display. The overlay UI will appear on the same monitor as the Roblox window.

### How do I report bugs or request features?

Please open an issue on this GitHub repository using the appropriate issue template (Bug Report or Feature Request). Include your Windows version, executor name, and steps to reproduce any problems for fastest resolution.
